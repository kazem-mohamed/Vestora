# 01 · نظرة عامة على المنتج

> اقرا الملف ده الأول. هو بيشرح **إيه** اللي المنصّة بتعمله و**ليه**، ومصطلحاته مستخدمة حرفيًا في باقي التوثيق وفي الكود.

---

## 1. المشكلة اللي بيحلّها

رائد أعمال عنده مشروع ومحتاج تمويل → مالوش طريقة يوصل بيها لمستثمرين حقيقيين ويثبت جدّيته.
مستثمر عنده فلوس ومحتاج فُرَص → مالوش طريقة يفرز بيها المشاريع ويتابع علاقته مع كل مؤسّس.

Vestora بتحلّ الاتنين في نظام واحد:

1. المؤسّس ينشر **venture** (مشروع + شروط الصفقة + الفريق + المستندات + خارطة الطريق).
2. **أدمن يراجع** الإعلان قبل ما يظهر للعامة (moderation gate).
3. المستثمر يكتشف المشاريع، يحفظها، ويقدّم **طلب دعم (support request)** بمبلغ.
4. المؤسّس يوافق أو يرفض، وبعدين يحرّك العلاقة على **pipeline** من 8 مراحل.
5. لما الاتنين يتفقوا، المؤسّس يعمل **funding request** بالمبلغ النهائي.
6. المستثمر يدفع (**sandbox**) → الفلوس تتسجّل، والعمولة تتخصم، والطرفين يتبلّغوا.
7. المؤسّس يقفل الجولة ويقول نتيجتها بصراحة (اكتملت / جزئية / انسحب).

## 2. المبدأ اللي المنتج كله متبني عليه: **الصدق**

ده مش كلام تسويقي — ده قرار معماري مكتوب في الكود نفسه وبيتفرض على مستوى قاعدة البيانات:

| القاعدة | ليه |
|---|---|
| **موافقة ≠ تمويل** (`Approved` ≠ `Funded`) | إن المؤسّس يقول "أيوه" مش معناه إن فلوس اتحرّكت. الاتنين رقمين منفصلين في كل شاشة. |
| **مفيش شارة "موثَّق" (Verified)** | Vestora مبتتحقّقش من هوية ولا شركة ولا أموال. بدلها فيه **Trust Signals** — كل إشارة بتقول بالظبط الحقيقة اللي المنصّة تقدر تثبتها ("تم تأكيد الإيميل"، "راجعه مشرف"). |
| **"reviewed" مش "vetted"** | الأدمن بصّ على الإعلان، مش دقّق حسابات الشركة. النصّ في الواجهة بيقول كده بالحرف. |
| **جولة مبتفضلش "بتجمع" للأبد** | لما المؤسّس يقفل الجولة، الإعلان يتحوّل لسِجلّ لما حصل، مش طلب مفتوح. |
| **كل المدفوعات محاكاة** | التطبيق بيرفض يشتغل أصلًا بمفتاح Stripe حقيقي (`sk_live_`). ده مشروع تخرّج، مش مرخّص ينقل فلوس. |

لو هتضيف أي feature، القاعدة دي هي أول اختبار: **هل الشاشة بتدّعي حاجة المنصّة متقدرش تثبتها؟**

## 3. المصطلحات (Glossary)

دي الكلمات المستخدمة في الكود وفي كل التوثيق. **متستخدمش مرادفات** — كل واحدة ليها معنى محدّد.

### الناس

| المصطلح | الشرح |
|---|---|
| **User** | الجدول الأساسي لكل الحسابات. النوع بيتحدّد بعمود `UserType` (TPH discriminator). |
| **Innovator** (= Founder / مؤسّس) | صاحب المشروع. بينشر ventures وبيستقبل طلبات الدعم. |
| **Investor** (مستثمر) | بيكتشف المشاريع، بيقدّم طلبات دعم، وبيدفع. |
| **Admin** (مشرف) | بيراجع الإعلانات، بيدير البلاغات، بيعلّق الحسابات، وبيشوف إيرادات المنصّة. |
| **Guest** (زائر) | من غير حساب. يقدر يتصفّح المشاريع والملفات العامة بس. |

### المشروع

| المصطلح | الشرح |
|---|---|
| **Venture / Project** | الإعلان نفسه. نفس الحاجة — `Project` في الكود، "venture" في نصوص الواجهة. |
| **ModerationStatus** | بوّابة الأدمن: `PendingReview` → `Approved` \| `Rejected`. من غير `Approved` المشروع مش ظاهر للعامة. |
| **LifecycleStatus** | تحكّم المؤسّس: `Active` \| `Paused` \| `Closed`. مستقلّ تمامًا عن الـ moderation. |
| **RoundOutcome** | لما الجولة تتقفل: `Completed` \| `PartiallyRaised` \| `Withdrawn` — **المؤسّس هو اللي بيقولها**، مش محسوبة من الأرقام. |
| **Stage** (بتاع المشروع) | مرحلة الشركة: `Idea` / `Pre-seed` / `Seed` / `Growth`. |
| **Data room** | مستندات المشروع، ومنها نوع `BackersOnly` اللي بيشوفه الداعمين المعتمَدين بس. |

### الفلوس — أهم 4 كلمات في المشروع كله

الترتيب ده ثابت رياضيًا: **Interest ≥ Committed ≥ Funded**.

| المصطلح | معناه بالظبط | مصدره |
|---|---|---|
| **Interest** | طلبات لسه المؤسّس مقرّرش فيها. **مش رأس مال.** | `Investment.Status == "Pending"` |
| **Committed** | المؤسّس قبل العلاقة. **لسه مش رأس مال** — دي نيّة معلَنة. | `Investment.Status == "Approved"` |
| **PaymentDue** | فيه funding request مفتوح وغير مدفوع. رأس مال **موعود**. | `FundingRequest.Status == "Open"` |
| **Funded** | دفعة تمّت فعلًا. **ده وبس اللي اسمه فلوس.** | `PaymentTransaction.Status == "Succeeded"` |

> ⚠️ الكلمة "raised" ممنوعة في الكود الجديد. لو مبلغ جاي من موافقة المؤسّس اسمه **committed**، ولو جاي من دفعة ناجحة اسمه **funded**. التعريف الوحيد للأربعة موجود في `Services/FundingMath.cs` — أي مكان تاني بيحسبهم بإيده = bug.

### العلاقة (Relationship)

| المصطلح | الشرح |
|---|---|
| **Investment** | صفّ العلاقة بين مستثمر ومشروع. **مش** تحويل فلوس. |
| **Status** | بوّابة التمويل: `Pending` → `Approved` \| `Declined`. |
| **Stage** | الـ pipeline الحقيقي: `New` → `Reviewing` → `Approved` → `Contacted` → `InDiscussion` → `Committed` → `Closed` (أو `Declined`). |
| **Deal room** | مساحة الشغل بين الطرفين: أسئلة، طلبات مستندات، ملاحظات خاصة، وحالة التمويل. |
| **FundingRequest** | طلب المؤسّس للمبلغ النهائي المتفق عليه. **واحد مفتوح بحد أقصى لكل علاقة** (مفروض بـ unique index). |
| **PaymentTransaction** | **محاولة** دفع واحدة. الفشل بيفضل مسجّل، وإعادة المحاولة بتعمل صفّ جديد مش بتصلّح القديم. |

### مصطلحات تانية

| المصطلح | الشرح |
|---|---|
| **Trust Signal** | حقيقة تقدر المنصّة تثبتها عن شخص أو مشروع. مش تقييم ومش مجموع في رقم واحد (عن قصد). |
| **Saved Search** | بحث محفوظ بيقول للمستخدم كام نتيجة جديدة ظهرت من آخر مرة شافه. |
| **Action Center** | قايمة "اللي مستنيك انت" — مبنية من طلبات مش متردود عليها، أسئلة مفتوحة، ودفعات مستحقّة. |
| **Endorsement / Review** | تزكية من مستثمر داعم لمشروع وصل هدفه. مؤهَّل بشروط، مش مفتوح لأي حد. |

## 5. رحلات المستخدم

> دي نظرة سريعة. **الرحلة الكاملة خطوة بخطوة بالطرفين — مع الحالات في قاعدة البيانات والإشعارات في كل مرحلة — في [11-INVESTMENT-FLOW.md](11-INVESTMENT-FLOW.md).**

### 5.1 التسجيل والدخول

```
تسجيل (POST /api/auth/register)
   ↓ الحساب اتعمل + كود تفعيل اتبعت بالإيميل
تفعيل الإيميل (POST /api/auth/verify-email)
   ↓
دخول (POST /api/auth/login) → accessToken (ساعة) + refreshToken (14 يوم)
   ↓
onboarding (مرّة واحدة لكل متصفّح) → الصفحة الرئيسية حسب الدور
```

**قواعد بتتفرض في الطريق:** الحساب لازم إيميله مفعَّل قبل الدخول · 5 محاولات دخول فاشلة = قفل 15 دقيقة · الحساب المعلَّق (`IsSuspended`) بيتمنع من الدخول ومتسجّل في `SecurityLog`.

### 5.2 المؤسّس: من فكرة لجولة مقفولة

```
/my-projects/new  → ينشئ المشروع (يبدأ PendingReview — مش ظاهر للعامة)
        ↓  أدمن يوافق
/projects/{id}    → الإعلان اتنشر · بيتبعت إشعار NewProject للمتابعين
        ↓  يبني الملف: صور · فريق · milestones · updates · مستندات
/dashboard/requests → طلبات دعم داخلة → يوافق أو يرفض
        ↓  الموافقة بتفتح deal room
/deals/{investmentId} → أسئلة · طلبات مستندات · ملاحظة خاصة
        ↓  الاتفاق على الرقم النهائي
"Request Funds" → FundingRequest (Open)
        ↓  المستثمر يدفع
Funded ✅ → الفلوس مسجّلة · العمولة متخصومة · الطرفين اتبلّغوا
        ↓
/dashboard/ventures → "Close round" → Completed / PartiallyRaised / Withdrawn
```

### 5.3 المستثمر: من اكتشاف لدفع

```
/projects  → بحث · فلاتر (قطاع/مكان/مرحلة/التزام) · ترتيب · حفظ
        ↓
/projects/{id} → التفاصيل · الفريق · الخريطة · المستندات العامة
        ↓
"Support" → مبلغ + طريقة تواصل → Investment(Pending)
        ↓  المؤسّس يوافق
/deals/{id} → deal room مفتوح · أسئلة · طلب مستندات
        ↓  المؤسّس يبعت funding request
"Complete investment" → checkout (sandbox) → /payments/return
        ↓  السيرفر بيتحقّق مع المزوّد (الـ redirect مش موثوق فيه أبدًا)
Funded ✅ → يظهر في /invest/portfolio و /invest/payments
```

### 5.4 الأدمن

```
/admin           → مؤشرات المنصّة + النمو
/admin/review    → الإعلانات المنتظرة → موافقة / رفض بسبب مكتوب
/admin/reports   → البلاغات → resolve / dismiss
/admin/users     → بحث · تعليق · استعادة · حذف (soft delete)
/admin/revenue   → عمولات المنصّة · المعاملات · refund
/admin/audit     → كل إجراء إداري اتعمل (AdminAuditLog)
/admin/security  → أحداث أمنية (دخول فاشل، قفل حساب، منع معلَّق)
```

### 5.5 المراسلة

محادثات مباشرة بين أي طرفين مسجّلين، مع **SignalR** لـ: الحضور (online/offline)، "بيكتب دلوقتي"، وإيصالات القراءة اللحظية. الرسالة ممكن تكون مربوطة بمشروع (`Message.ProjectId`) فتبقى المحادثة في سياقه. المرفقات: صور بس دلوقتي.

## 6. اللي Vestora **مش** بتعمله (عن قصد)

عشان محدش يبني على افتراض غلط:

- ❌ **مبتنقلش فلوس حقيقية.** Sandbox بس — والتطبيق بيرفض يقلع بمفتاح إنتاج.
- ❌ **مبتتحقّقش من هوية** ولا من شركة ولا من مصدر أموال (لا KYC ولا AML).
- ❌ **مبتحتفظش بعقود** ولا اتفاقيات ملزمة. الاتفاق النهائي بيحصل خارج المنصّة.
- ❌ **مفيش equity ledger** ولا cap table ولا إدارة أسهم.
- ❌ **مفيش نظام صلاحيات دقيق** — أدوار خشنة بس (`[Authorize(Roles=…)]`).
- ❌ **مفيش تخزين ملفات خارجي** — الصور والمستندات كلها `varbinary` جوّه قاعدة البيانات.
