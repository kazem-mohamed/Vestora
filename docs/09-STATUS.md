## 2. شغّال بحدود معروفة ⚠️

| البند | الحدّ | الأثر |
|---|---|---|
| **حماية الأدوار في الواجهة** | `RequireAuth` بيشتغل على العميل — الصفحة بتتحمّل الأول وبعدين بتوجّه | مش ثغرة أمنية (الـ backend بيحمي فعليًا)، بس فيه ومضة قبل التوجيه |
| **الملفات في قاعدة البيانات** | كل الصور والمستندات `varbinary` | حجم القاعدة بيكبر، ومصرف ذاكرة عند التنزيل. مقايضة مقصودة — مفيش تخزين خارجي في نطاق المشروع |
| **المدفوعات sandbox** | مفيش فلوس حقيقية بتتحرّك، والتطبيق بيرفض مفتاح إنتاج | **مقصود** — مشروع تخرّج غير مرخّص |
| **الأدوار خشنة** | `[Authorize(Roles=…)]` فقط، مفيش permissions دقيقة | إضافة أدوار وسيطة هتحتاج شغل |
| **ترقية الأدمن يدوية** | bootstrap secret أو تعديل في القاعدة | عملية هشّة، بس مقبولة للحجم الحالي |
| **`onboarding` لكل متصفّح** | علامة في `localStorage`، مفيش حقل في الـ backend | بيتكرّر على جهاز جديد |
| **المرفقات صور بس** | `MessageAttachment` بيقبل الصور فقط | الملفات التانية (PDF مثلًا) مؤجّلة |
| **`ProjectsController.CreateProject`** | بيفحص الدور يدويًا بـ `User.IsInRole` بدل السمة | اتساق، مش أمان |
| **قاعدة بيانات واحدة مشتركة** | مفيش نسخة محلّية | أي migration بيمسّ التيم كله فورًا |

## 3. الثغرات الحقيقية 🔴

| # | الثغرة | الأثر | الحل |
|---|---|---|---|
| 1 | **المشروع مش تحت Git** | مفيش version control ولا استرجاع ولا مراجعة كود ولا فروع | `git init` + `.gitignore` موجود وجاهز فعلًا |
| 2 | **مفيش أي اختبارات** | صفر automated tests — كل تحقّق يدوي | ابدأ بـ integration tests على `FundingMath` و`PaymentService` (أعلى مخاطرة) |
| 3 | **مفيش CI/CD** | مفيش `.github/` ولا pipeline | بعد الـ git |
| 4 | **مفيش خطة نشر (deployment)** | فيه `Properties/PublishProfiles` بس مفيش توثيق للعملية | وثّق خطوات النشر على MonsterASP |
| 5 | **مفيش `.env.example`** | مطوّر جديد لازم يقرا التوثيق عشان يعرف المفاتيح | ضيف `.env.example` للـ frontend |
| 6 | **مفيش مراقبة أو تجميع لوجات** | اللوجات على الـ console فقط | Serilog + sink لو هيتنشر |

## 4. اللي مش موجود عن قصد (خارج النطاق)

مش نواقص — دي قرارات:

- ❌ **KYC / AML / التحقّق من الهوية**
- ❌ **نقل فلوس حقيقي** أو ترخيص مالي
- ❌ **العقود وcap table وequity ledger**
- ❌ **شارة "Verified"** — بدلها Trust Signals بحقائق محدّدة
- ❌ **مؤشّر تقييم رقمي واحد** — بيدعو لمقارنة الحقائق متسندهاش
- ❌ **تخزين ملفات خارجي (S3/Blob)**
- ❌ **تطبيق موبايل** — الويب responsive
- ❌ **تعدّد لغات أكتر من EN/AR**

## 5. الخطوات التالية المقترَحة (بالأولوية)

### فورًا
1. **`git init` + أول commit.** مفيش أي شغل تاني يستاهل يتعمل قبله.
2. **`.env.example`** للـ frontend.
3. **تنضيف الكود الميّت** (`WeatherForecast.cs`, `path/to/`) بعد مراجعة.

### قريب
4. **اختبارات على المسار المالي** — `FundingMath` (الأرقام الأربعة، الحدود، حالة العلاقة) و`PaymentService` (التسوية، الـ idempotency، الـ refund، سباق الـ webhook/verify).
5. **CI بسيط** — `dotnet build` + `npm run build` على كل push.
6. **توثيق النشر** خطوة بخطوة.

### متوسّط
7. **حماية أدوار على مستوى السيرفر** — لو التوكن اتنقل لـ httpOnly cookie، يبقى ممكن تتعمل في middleware.
8. **تخزين ملفات خارجي** — يخفّف القاعدة ويحسّن التنزيل.
9. **`onboarding` كحقل في الحساب** بدل `localStorage`.
10. **مرفقات غير الصور** في المراسلة.

### طويل
11. **permissions دقيقة** لو ظهرت أدوار وسيطة.
12. **مراقبة ولوجات مجمَّعة**.
13. **واجهة لإدارة الأدوار** بدل ترقية القاعدة اليدوية.
