# خطة اختبار يدوي — الواجهة الأمامية (Vestora)

ملف عملي، مش نظري. كل سطر فيه سيناريو تجرّبه بإيدك، وتسجّل النتيجة في
عمود **النتيجة الفعلية** وتحطّ ✅ أو ❌ في عمود **الحالة**. الملف مش
كود — الفرونت مفيش فيه أي أداة اختبار آلي أصلًا (Jest/Playwright/غيرهم)،
فده الطريقة الحقيقية الوحيدة دلوقتي للتأكد إنه شغّال.

---

## قبل ما تبدأ

### الأدوات

| الأداة | لإيه |
|---|---|
| Node.js + npm | تشغيل الفرونت |
| .NET 8 SDK | تشغيل الـ API عشان الصفحات تجيب بيانات حقيقية |
| متصفّح بأدوات مطوّر (Chrome/Edge) | تفحص الـ Console والـ Network والـ URL |
| حسابين على الأقل | واحد Innovator وواحد Investor — عشان تجرّب التفاعل بين الاتنين |
| حساب Admin | لو محتاج تجرّب صفحات الأدمن (اتعمل مباشرة في الداتابيز لو مفيش تسجيل عام له) |

### التشغيل

```bash
cd Frontend/vestora
npm install
npm run dev
```

```bash
cd MyAppApi/MyAppApi
dotnet run
```

الفرونت بيفتح على `http://localhost:3000`. لو الـ API رفض يشتغل بسبب مفتاح
Stripe — **ده مقصود**، لازم مفتاح تجريبي يبدأ بـ `sk_test_`.

### إزاي تسجّل نتيجة

- **✅ نجح**: الشاشة عملت بالظبط زي المتوقّع.
- **❌ فشل**: اكتب في عمود «النتيجة الفعلية» *بالظبط* إيه اللي حصل —
  رسالة الخطأ، الشكل الغلط، أو أي حاجة غير متوقّعة. لو فيه رسالة خطأ في
  الـ Console، انسخها.
- لو مش متأكد الحالة المتوقّعة صح ولا لأ، اسأل قبل ما تسجّل ❌.
